# Mercedes Portrait Intake

Upload `mercedes-portfolio-selected.zip` into this folder on branch:

`portfolio/mercedes-session-update`

The ZIP contains six selected photographs with descriptive filenames and a mapping back to the original camera filenames.

Do not add the rejected images from the original 23-photo session ZIP.

After upload, the assistant will extract the selected files, create web-optimized copies, add them to the Portraits & Seniors portfolio, remove this temporary intake package from the branch, run verification, and open a draft PR for approval.
