# Upload new portfolio photos here

Use this branch for future portfolio intake:

`portfolio/photo-intake`

## Simple workflow

1. Stay on the `portfolio/photo-intake` branch.
2. Create a dated session folder inside `portfolio-intake/`, for example:
   `portfolio-intake/2026-08-back-to-school/`
3. Upload the finished JPEGs or one ZIP into that folder.
4. Tell ChatGPT the folder name and confirm the photos are approved for public portfolio use.
5. ChatGPT will select the strongest images, place them in the correct website categories, optimize public copies, remove temporary intake files, run checks, and open a preview PR.

Never upload private client-gallery photos here unless public portfolio use is confirmed. This branch is an intake workspace and should not be merged into `main` directly.
