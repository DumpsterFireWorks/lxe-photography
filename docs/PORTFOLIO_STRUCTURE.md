# LXE Photography Portfolio Structure

The website is organized as a multi-page site rather than one long homepage.

## Public pages

- `/portfolio/` — portfolio category landing page
- `/portfolio/families/`
- `/portfolio/couples-engagements/`
- `/portfolio/portraits-seniors/`
- `/portfolio/motherhood-newborns/`
- `/portfolio/minis-seasonal/`
- `/portfolio/pets-lifestyle/`
- `/sessions/` — pricing, inclusions, add-ons, and payment guidance
- `/about/` — Lexus’s story and the client experience
- `/contact/` — inquiry form and social links

## Future image folders

New approved portfolio photographs should be organized under:

- `public/images/portfolio/families/`
- `public/images/portfolio/couples-engagements/`
- `public/images/portfolio/portraits-seniors/`
- `public/images/portfolio/motherhood-newborns/`
- `public/images/portfolio/minis-seasonal/`
- `public/images/portfolio/pets-lifestyle/`

Existing photographs remain in `public/images/portfolio/` so current URLs do not break. New work should use the category folders.

## Publishing rule

1. Finish the client gallery.
2. Deliver the private gallery to the client.
3. Confirm portfolio and social-media permission.
4. Upload only approved selections.
5. Add the approved files to the matching category page.

Do not publish unfinished, undelivered, or unapproved client photographs.

## File naming

Use clear lowercase names with hyphens, for example:

- `family-lake-michigan-laughing-01.jpg`
- `engagement-shoreline-ring-01.jpg`
- `senior-blue-dress-pines-01.jpg`
- `mother-newborn-lakeside-01.jpg`

Avoid camera-generated names such as `IMG_1234.jpg` for future uploads when practical.
