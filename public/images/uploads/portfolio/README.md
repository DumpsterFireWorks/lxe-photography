# Portfolio Upload Drop Folder

Upload Lexus's finished portfolio photographs here.

## What belongs here

- Final edited JPEG or PNG files
- Client-approved photographs that may be shown publicly
- Portraits, families, couples, seniors, pets, graduation, and seasonal sessions

## Naming

Descriptive names are helpful but not required. Examples:

- `family-smith-sunset-01.jpg`
- `senior-emma-downtown-01.jpg`
- `couple-beach-01.jpg`
- `pet-session-bella-01.jpg`

## Workflow

New files uploaded here are an intake batch. They can then be reviewed, optimized for the web, renamed consistently, categorized, and placed into the live portfolio layout.

Do not upload RAW camera files here. Use finished edited exports only.
